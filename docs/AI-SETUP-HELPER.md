# Stuck? Let an AI assistant walk you through it

This bot is free and comes with **no personal support**. If you get stuck, an AI assistant (Claude, ChatGPT, Gemini, Copilot…) can take you through the setup one step at a time and explain any error.

**How:** open your AI assistant, copy everything in the box below, fill in the two `[brackets]`, and send it. Then do what it says, one step at a time.

```
I'm setting up "A2A Analyse Bot", a free open-source Discord bot that checks Amazon UK products for resellers. It runs on my own Cloudflare account with my own Keepa key (and optionally my own Amazon SP-API keys).

The full instructions are here: https://github.com/aydeng1298/a2a-analyse-bot
Please read the README on that page (and docs/A2A-Analyse-Bot-Setup-Guide.pdf if you can open it) before you start. If you can't open links, tell me and I'll paste the README text to you.

My computer: [Mac or Windows]
Do I want to connect my Amazon seller account (SP-API) now: [yes / no / not sure]

How I'd like you to help:
- I'm not technical. Take me through ONE step at a time, in plain English.
- Tell me exactly what to click, where, and what to type. Put anything I need to type or paste in a box so I can copy it.
- After each step, wait for me to say "done" or paste what I see before you give me the next step.
- If I paste an error message, explain what it means in plain English and tell me the fix.
- The setup is: install Node.js, create a Discord application and bot, get a Keepa API key, (optionally) create a private Amazon SP-API app, download the project ZIP from GitHub, run "npm run setup" in a terminal inside the project folder, paste the /interactions address into the Discord app's "Interactions Endpoint URL", then invite the bot to my server.
- IMPORTANT: never ask me to paste my bot token, Keepa key, Amazon keys or any password into this chat. The setup command asks for them privately in the terminal; I'll paste them there.
- Don't suggest changing the bot's code. If something in the instructions seems wrong, tell me and suggest the simplest workaround.

Start with step 1.
```

## Tips
- **Never paste your keys or tokens into an AI chat**, a Discord message or anywhere public. Only paste them into the terminal when the setup asks.
- If the AI can't open the GitHub link, open the page yourself, copy the README text and paste it in.
- If something fails, copy the **whole error text** from the terminal and paste it to the AI. Screenshots work too with most assistants.
